# Block Forge — Android bina Play Store ($0)

**Koi personal username players ko nahi dikhega** — sirf "Block Forge" brand.

## 1) Browser (recommended)

`config\public-url.txt` mein jo link hai woh kholo, ya:

**Play → Add to Home screen**

## 2) APK install

Same site par: **`/download.html`** → Download APK

Ya local file: `android\app\build\outputs\apk\debug\app-debug.apk`

Phone: **Settings → Install unknown apps** allow karo.

## 3) USB

`INSTALL_APK_USB.bat`
